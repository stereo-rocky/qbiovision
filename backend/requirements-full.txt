#   quantum_backend.py -> Qiskit 1.x circuits + Aer simulator + QML kernels
#   noise_mitigation.py-> Aer noise models + mitiq ZNE
#   benchmarking.py    -> PyTorch classical CNN baseline
#   ml_compat.py       -> scikit-learn metrics / SVC
#   imaging_compat.py  -> OpenCV + Matplotlib
#   report_generator.py-> WeasyPrint PDF rendering
