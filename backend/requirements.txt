# ─────────────────────────────────────────────────────────────────────────────
# Q-BioVision — DEPLOYMENT (serverless) requirements
#
# This is the dependency set installed into the Vercel Python Function.
# Vercel enforces a 225 MB unzipped function bundle; this set installs to
# ~122 MB. Every package below is imported by a production API route.
#
# The heavy ML / quantum / imaging stack (torch, torchvision, qiskit,
# qiskit-aer, qiskit-machine-learning, mitiq, scikit-learn, scipy,
# opencv-python-headless, matplotlib, weasyprint, pydicom) lives in
# requirements-full.txt and is installed for local development only — each of
# those packages on its own exceeds the serverless budget (scipy ~214 MB,
# qiskit ~261 MB, scikit-learn ~273 MB, opencv ~225 MB, matplotlib ~169 MB,
# torch + CUDA wheels ~5.9 GB).
#
# The backend degrades gracefully: quantum_backend.py / ml_compat.py /
# imaging_compat.py prefer the real libraries when present and otherwise use
# the pure-NumPy implementations in qlite.py, so every endpoint keeps working.
#
#   Local full install:  pip install -r requirements-full.txt
# ─────────────────────────────────────────────────────────────────────────────
